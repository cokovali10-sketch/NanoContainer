Features

🐧

Pure Linux

Direct syscall usage — clone(), pivot_root(), mount(), seccomp(). No container libraries.

🔒

Security

Seccomp BPF filters, Linux capabilities, read-only rootfs, no-new-privileges, encrypted secrets.

🌐

Networking

Bridge networking, veth pairs, NAT, DNS service discovery, port forwarding.

📦

Compose

Multi-container orchestration from YAML/JSON. Dependency resolution, rolling updates.

🖥️

Web Dashboard

Real-time dark-themed UI. Monitor containers, view logs, manage services.

🔄

Orchestration

Service replication, load balancing, health checks, restart policies.

Quick Start

# One-line install
curl -fsSL https://raw.githubusercontent.com/cokovali10-sketch/NanoContainer/master/scripts/install.sh | bash

# Or build from source
git clone https://github.com/cokovali10-sketch/NanoContainer.git
cd NanoContainer && make build

# Run your first container
sudo ./nanocontainer run alpine /bin/sh
/ # echo "Hello from NanoContainer!"
Hello from NanoContainer!

# Start the web dashboard
sudo ./nanocontainer serve --addr :8080
NanoContainer v3.0.0 running on http://localhost:8080
